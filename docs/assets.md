# Assets, sources and rights

Everything shipped in `public/` is either generated by this repository's scripts, supplied by FAST, or
taken from a source whose licence allows commercial web use. Nothing is loaded from a CDN at runtime.

## Rebuilding from sources

- HDRIs: download the 4k `.hdr` of the two Poly Haven skies into `../_downloads/hdri/`.
- Textures: download the 1k diffuse JPGs named in `tools/textures.mjs` into `../_downloads/tex/`, then `node tools/textures.mjs`.
- Character: `tools/blender/character/fetch_sources.sh` then `build.sh all`.
- Scenes: `bash tools/bake.sh <names>` (see the README).
